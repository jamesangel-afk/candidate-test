# Document Dashboard — React Exercise

## Setup

```bash
npm install
```

## Run the UI

```bash
npm run dev
```

Opens the app at http://localhost:5173. You'll see it crash — that's intentional.

## Run the Tests

```bash
npm test
```

All 6 tests will fail. Your job is to fix the component in `src/DocumentDashboard.jsx` until the app works and every test passes.

You may refactor freely but **do not modify the test file**.

Good luck!
